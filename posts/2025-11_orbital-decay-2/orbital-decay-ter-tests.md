# The Expanse RPG Tests For GURPS TS Orbital Decay Scenario<!-- omit from toc -->

This document list proposed tests in `The Expanse RPG` system that could be considered the equivalent of those used in the `Orbital Decay` scenario for `GURPS Transhuman Space`.

| Situation                                                                | GURPS Test                     | TER Equivalent                   |
| :----------------------------------------------------------------------- | :----------------------------- | :------------------------------- |
| Closing pressure doors manually (p. 6)                                   | ST -2                          | Strength (Might) TN 13           |
| Bypassing security to open doors (p. 6)                                  | Electronics Ops (Sec. Sys.)    | Intelligence (Security) TN 11    |
| Bypassing a biometric scan-lock to Red Sector (p.7)                      | Electronics Ops (Sec. Sys.) -6 | Intelligence (Security) TN 17    |
| Bypassing security override code from Ops Center security console (p. 7) | Electronics Ops (Sec. Sys.) -8 | Intelligence (Security) TN 19    |
| EVA to transfer from shuttle to station airlock (p.13)                   | Free Fall / Vacc Suit          | Dexterity (Free-Fall) TN 11      |
| Restarting Computer from Ops Center station (p. 14)                      | Computer Hacking -6            | Intelligence (Security) TN 17    |
| Retrieving Data from damaged computer memory banks (p. 14)               | Computer Ops -3                | Intelligence (Technology) TN 15  |
| Overriding security of env. control to set dangerous params (p. 14)      | Computer Hacking -6            | Intelligence (Security) TN 17    |
| Unlocking main airlock inner door (p. 15)                                | Electronics Ops (Sec. Sys.) -3 | Intelligence (Security) TN 15    |
| Crawling away from hull breach during decompression (p. 17)              | Climbing / ST -5               | Strength (Climbing) TN 17        |
| Avoiding being swept off one's feet by decompression (p. 17)             | DX                             | Dexterity TN 11                  |
| Avoiding gravity fluctuations after collision (p. 17)                    | DX -8                          | Dexterity TN 19                  |
| Studying station's orbit or movements (p. 17)                            | Astrogation                    | Intelligence (Navigation) TN 11  |
| Unscrambling station's records using partial password (p. 22)            | Computer Ops -5                | Intelligence (Technology) TN 17  |
| Calling up each unscrambled record from damaged data banks (p. 22)       | Computer Ops -3                | Intelligence (Technology) TN 15  |
| Using Red Sector genetic lab for analysis (p. 22)                        | Genetics (Genetic Eng.) +0     | Intelligence (Science) TN 11     |
| Using Sick Bay damaged small genetic lab for analysis (p. 22)            | Genetics (Genetic Eng.) -5     | Intelligence (Science) TN 17     |
| Rushing analysis time (x0.5) (p. 22)                                     | -4 cumulative                  | TN +2 cumulative                 |
| Repairing/rewiring systems/lighting (p. 24)                              | Electronics / Eng.             | Intelligence (Technology) TN 11  |
| Restoring Fusion Reactor cooling (p. 24)                                 | Electronics Operation / Eng.   | Intelligence (Technology) TN 11  |
| Bypassing security (Ops Center) to (de)activate autodestruction (p. 29)  | Electronics Ops (Sec. Sys.) -6 | Intelligence (Security) TN 17    |
| Hot-wiring autodestruction nuclear warhead (p. 29)                       | Demolition -3                  | Intelligence (Demolitions) TN 15 |
| Undocking Negative Growth ship (p. 30)                                   | Piloting (Hi Perf Craft) -6    | Dexterity (Piloting) TN 17       |
| Bypassing Negative Growth ship controls lock (p. 30)                     | Computer Hacking -4            | Intelligence (Security) TN 15    |
| Dodging station's debris (p. 30)                                         | Piloting (Hi Perf Craft)       | Dexterity (Piloting) TN 11       |
